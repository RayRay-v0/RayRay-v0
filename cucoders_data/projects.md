# Proyectos

## Renovables Cuba

- Demo: https://renovables-cuba-frontend.vercel.app/
- Tipo: catálogo ecommerce / energía solar
- Stack: React, TanStack Start, TypeScript, Tailwind CSS, shadcn/ui, Vite, React Query

Catálogo de productos solares y energía de respaldo para hogares en Cuba. Incluye categorías, búsqueda, filtros, carrito, precios multidivisa, guías solares y flujo de solicitud por WhatsApp.

Trabajo realizado:

- Arquitectura de catálogo por categorías.
- Carrito y flujo de checkout por WhatsApp.
- UI responsive para desktop y mobile.
- Soporte de contenido bilingüe mediante i18n.
- Componentes de navegación, filtros y fichas de producto.

## Arca Ilary

- Demo: https://catering-landing-sigma.vercel.app/
- Tipo: landing comercial / catering
- Stack: React, Vite, TypeScript, Tailwind CSS, shadcn/ui, i18next, JSON-LD

Sitio bilingüe para un servicio de catering cubano, orientado a presentar la oferta con claridad, SEO estructurado y un flujo de cotización que lleva el contexto del pedido a WhatsApp.

Trabajo realizado:

- Landing page responsive.
- Contenido bilingüe.
- SEO estructurado con JSON-LD.
- Flujo de conversión por WhatsApp.
- Interfaz visual alineada con la oferta comercial.

## Ritmo Habana

- Demo: https://ritmo-habana.vercel.app/
- Tipo: landing page / clases de baile
- Stack: React, Vite, TypeScript, Tailwind CSS, shadcn/ui, Embla Carousel, lucide-react

Landing page para clases de salsa y baile popular cubano. Organiza información clave como horarios, precios, estilos de baile, instructores y contacto.

Trabajo realizado:

- Hero carousel con autoplay controlado.
- Secciones responsive para estilos, horarios y precios.
- Datos separados del JSX.
- Optimización de imágenes a WebP.
- Preparación para despliegue estático.
