# Servicios

## Frontend/UI Engineering

Construcción de interfaces web con React, Next.js, Vite y TypeScript. El foco no es solo que la página se vea bien, sino que sea clara, responsive, mantenible y fácil de usar.

Incluye:

- Implementación de landing pages, portafolios, catálogos y frontends comerciales.
- Componentes reutilizables.
- Layouts responsive.
- Estados interactivos claros.
- Integración con datos, formularios, rutas y CTAs.
- Corrección de bugs visuales y de comportamiento.

## Landing pages comerciales

Páginas enfocadas en explicar una oferta y llevar al usuario a una acción concreta: contacto, reserva, cotización, compra o demo.

Incluye:

- Estructura de secciones.
- Copy orientado a conversión.
- Hero, beneficios, servicios, proceso, prueba visual y contacto.
- Integración con WhatsApp, formularios o enlaces externos.
- SEO básico y metadatos.
- Preparación para deploy en Vercel o Netlify.

## Catálogos y flujos ecommerce ligeros

Frontends para mostrar productos o servicios con búsqueda, categorías, filtros, carrito o solicitud de compra.

Incluye:

- Catálogo por categorías.
- Tarjetas de producto.
- Búsqueda y filtros.
- Carrito o selección de productos.
- Checkout por WhatsApp o formulario.
- Precios, estados de disponibilidad y mensajes comerciales.

## Motion e interacción

Animaciones y microinteracciones con propósito. No se trata de llenar una página de efectos: se usan para guiar la atención, explicar estados o reforzar la navegación.

Incluye:

- GSAP.
- Framer Motion.
- Animaciones de entrada.
- Scroll guiado.
- Transiciones entre secciones.
- Estados hover/focus.

## Experiencias 3D y WebGL

Integración de Three.js y React Three Fiber para añadir una capa visual cuando el proyecto lo justifica, especialmente en portafolios, marcas creativas y landing pages premium.

Incluye:

- Escenas 3D para hero o fondo visual.
- Integración con UI React.
- Optimización básica para rendimiento.
- Control de interacción y movimiento.
- Composición visual alineada con la marca.

## Auditoría y mejora de interfaces existentes

Revisión de interfaces ya construidas para detectar problemas de claridad, responsive, conversión, rendimiento visual o consistencia.

Incluye:

- Diagnóstico de UI/UX.
- Corrección de bugs visuales.
- Ajustes responsive.
- Mejora de jerarquía, spacing y legibilidad.
- Refactor puntual sin rehacer todo el proyecto.
- Verificación antes de publicar.

## Implementación de diseño a código

Conversión de referencias visuales, mockups o criterios de marca en componentes reales.

Incluye:

- Lectura de referencia visual.
- Implementación fiel dentro de las limitaciones técnicas.
- Adaptación responsive.
- Componentización.
- Revisión de detalles: tipografía, espaciado, contraste y estados.

## Forma de trabajo

- Alcance claro antes de construir.
- Cambios puntuales, no refactors innecesarios.
- Verificación local antes de dar algo por terminado.
- Preferencia por soluciones simples, mantenibles y desplegables.
- Comunicación directa sobre limitaciones, riesgos y decisiones técnicas.
