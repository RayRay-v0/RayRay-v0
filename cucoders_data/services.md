# Servicios

## Frontend/UI Engineering

Construccion de interfaces web con React, Next.js, Vite y TypeScript. El foco no es solo que la pagina se vea bien, sino que sea clara, responsive, mantenible y facil de usar.

Incluye:

- Implementacion de landing pages, portafolios, catalogos y frontends comerciales.
- Componentes reutilizables.
- Layouts responsive.
- Estados interactivos claros.
- Integracion con datos, formularios, rutas y CTAs.
- Correccion de bugs visuales y de comportamiento.

## Landing pages comerciales

Paginas enfocadas en explicar una oferta y llevar al usuario a una accion concreta: contacto, reserva, cotizacion, compra o demo.

Incluye:

- Estructura de secciones.
- Copy orientado a conversion.
- Hero, beneficios, servicios, proceso, prueba visual y contacto.
- Integracion con WhatsApp, formularios o enlaces externos.
- SEO basico y metadatos.
- Preparacion para deploy en Vercel o Netlify.

## Catalogos y flujos ecommerce ligeros

Frontends para mostrar productos o servicios con busqueda, categorias, filtros, carrito o solicitud de compra.

Incluye:

- Catalogo por categorias.
- Tarjetas de producto.
- Busqueda y filtros.
- Carrito o seleccion de productos.
- Checkout por WhatsApp o formulario.
- Precios, estados de disponibilidad y mensajes comerciales.

## Motion e interaccion

Animaciones y microinteracciones con proposito. No se trata de llenar una pagina de efectos: se usan para guiar la atencion, explicar estados o mejorar la percepcion de calidad.

Incluye:

- GSAP.
- Framer Motion.
- Animaciones de entrada.
- Scroll guiado.
- Transiciones entre secciones.
- Estados hover/focus.

## Experiencias 3D y WebGL

Integracion de Three.js y React Three Fiber para experiencias visuales diferenciadas, especialmente en portafolios, marcas creativas y landing pages premium.

Incluye:

- Escenas 3D para hero o fondo visual.
- Integracion con UI React.
- Optimizacion basica para rendimiento.
- Control de interaccion y movimiento.
- Composicion visual alineada con la marca.

## Auditoria y mejora de interfaces existentes

Revision de interfaces ya construidas para detectar problemas de claridad, responsive, conversion, rendimiento visual o consistencia.

Incluye:

- Diagnostico de UI/UX.
- Correccion de bugs visuales.
- Ajustes responsive.
- Mejora de jerarquia, spacing y legibilidad.
- Refactor puntual sin rehacer todo el proyecto.
- Verificacion antes de publicar.

## Implementacion de diseno a codigo

Conversion de referencias visuales, mockups o criterios de marca en componentes reales.

Incluye:

- Lectura de referencia visual.
- Implementacion fiel dentro de las limitaciones tecnicas.
- Adaptacion responsive.
- Componentizacion.
- Revision de detalles: tipografia, espaciado, contraste y estados.

## Forma de trabajo

- Alcance claro antes de construir.
- Cambios puntuales, no refactors innecesarios.
- Verificacion local antes de dar algo por terminado.
- Preferencia por soluciones simples, mantenibles y desplegables.
- Comunicacion directa sobre limitaciones, riesgos y decisiones tecnicas.
